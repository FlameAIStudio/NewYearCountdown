# **🎆 GoogleAIStudio-2026 New Year Countdown 🎆**

A high-end, cinematic 2026 New Year countdown experience featuring dynamic canvas fireworks, glass-morphism UI, and sophisticated animation sequences.
![Preview](./GoogleAIStudio-Preview.gif)

## Features

- **Cinematic Visuals**: Deep space background with dynamic particles.
- **Glass-morphism UI**: Modern, sleek interface design.
- **Audio Experience**: High-fidelity sound effects using Google GenAI (or local fallback).
- **Interactive**: "Initiate" sequence with haptic feedback visualization.
- **Grand Finale**: Massive fireworks display at midnight.

## Setup

1.  **Clone the repository**
2.  **Install dependencies**:
    ```bash
    npm install
    ```
3.  **Configure API Key**:
    - Create a `.env` file in the root directory.
    - Add your Google Gemini API key:
      ```
      GEMINI_API_KEY=your_api_key_here
      ```

## Development

```bash
npm run dev
```
